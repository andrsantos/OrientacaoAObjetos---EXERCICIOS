### Comando do Exercício ###
Elabore uma classe Produto com os seguintes atributos:

     nome
     preco
     quantidadeEstoque

e os seguintes métodos:

reporEstoque(quantidade) — aumenta a quantidade em estoque
vender(quantidade) — diminui a quantidade em estoque (não pode vender mais do que existe)
aplicarDesconto(percentual) — recebe o percentual de desconto e atualiza o preço

Crie uma classe de teste que:
- Crie pelo menos dois produtos
- Repoha estoque
- Venda unidades
- Aplique desconto
- Mostre os dados dos produtos antes e depois das operações
